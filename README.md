# Shared Ptr

Собственная реализация умных указателей с подсчётом ссылок на C++.

## Инструментарий

- C++17, стандартная библиотека C++.
- Google Test — модульные тесты.
- clang-format и clang-tidy — форматирование и статический анализ.

## Что реализовано

- `shared_ptr<T>` — совместное владение объектом с автоматическим освобождением памяти и подсчётом ссылок.
- `weak_ptr<T>` — слабые ссылки с получением владеющего указателя через `lock()`.
- `make_shared<T>` — создание объекта и управляющего блока за одно выделение памяти.
- Копирование и перемещение указателей, преобразования совместимых типов, пользовательские функции удаления и aliasing-конструкторы.
- Операции `reset`, `swap`, доступ к объекту и сравнение указателей.

## Запуск тестов

При установленном Google Test выполнить из корня проекта: `g++ -std=c++17 -Isrc test/*.cpp -lgtest_main -lgtest -pthread -o /tmp/shared-ptr-tests && /tmp/shared-ptr-tests`.
